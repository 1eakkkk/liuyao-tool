# AI 六爻问卦 · 自动起卦 + DeepSeek 解卦

> 🔮 一款桌面小工具：输入你的问题，自动起卦排盘，再调用 DeepSeek AI 生成白话解读，几秒钟获得卦象参考。  
> 🚀 **下载地址**：[Releases 页面](https://github.com/1eakkkk/liuyao-tool/releases)（Windows 版 `.exe`）

## ✨ 特点

- **自动起卦排盘**：基于传统火珠林纳甲法，自动计算六亲、世应、纳甲、空亡，无需手动查表。
- **AI 智能解读**：集成 DeepSeek API，根据卦象和你的问题生成个性化解卦内容。
- **开箱即用**：单个 `.exe` 文件，无需安装任何环境，双击即可运行。
- **本地存储**：API Key 保存在你电脑本地，下次打开无需重复输入。
- **一键复制**：解卦结果支持复制，方便分享或保存。

## 📦 准备工作

使用本工具前，你需要一个 **DeepSeek API Key**（用于调用 AI）。

1. 访问 [DeepSeek 平台](https://platform.deepseek.com) 注册/登录。
2. 进入 **API Keys** 页面，点击“创建新的 API Key”。
3. 复制生成的一长串字符（类似 `sk-xxxxxxxxxxxxxxxx`），**务必保存到记事本**，关闭页面后不再显示原文。

> 💡 API 费用由 DeepSeek 直接向你收取，与工具作者无关，作者也无法看到你的 Key。

## 🚀 快速开始

1. **下载软件**：从 [Releases](https://github.com/1eakkkk/liuyao-tool/releases) 下载最新版的 `六爻问卦.exe`。
2. **首次运行**：双击 `六爻问卦.exe`，会弹出提示框要求输入你的 DeepSeek API Key。
3. **粘贴 Key**：将之前保存的 `sk-` 开头的字符串粘贴进去，点击确定。
4. **开始问卦**：
   - 在输入框中写下你想问的问题（例如：“最近想跳槽，合不合适？”）
   - 点击 **“起卦解读”** 按钮
   - 稍等几秒，下方会显示 AI 生成的回帖内容
   - 点击 **“复制结果”** 即可分享

## ⚙️ 配置管理

- **更换 API Key**：点击软件左上角菜单栏 **“设置”** → **“更改 DeepSeek API Key”**，重新输入即可。
- **Key 存储位置**：保存在你电脑本地（Windows 注册表或配置文件中），卸载软件后需重新设置。

## ❓ 常见问题

**Q: 点“起卦解读”后一直卡住或报错“找不到浏览器”？**  
A: 本工具默认使用 Edge 浏览器内核，若你的系统精简了 Edge，请打开命令提示符，切换到软件目录，运行：
```
六爻问卦.exe --install-browsers
```
这会自动安装一个备用浏览器组件。

**Q: 提示 API Key 无效或调用失败？**  
A: 请检查：
- Key 是否完整（开头必须是 `sk-`）
- DeepSeek 账户是否有余额（新用户通常有赠送额度）
- 网络是否正常

**Q: 我的问题会被上传到其他地方吗？**  
A: 你的问题、排盘数据仅发送给 DeepSeek 服务器用于生成解卦内容（这是 AI 服务的必要步骤），**不会**上传到其他任何第三方服务器。

**Q: 解卦结果可靠吗？**  
A: 六爻属于传统文化中的象数推演，AI 解读仅供参考和娱乐，**不建议**作为医疗、法律、财务等重大决策的唯一依据。涉及健康、人身安全等问题，请务必咨询专业人士。
