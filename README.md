# 🏮 六爻排盘 · 自动纳甲（纯前端开源版）

> 🔮 一个无需后端、纯 HTML + CSS + JavaScript 编写的简易六爻自动排盘工具。严格按照传统火珠林纳甲法编写。
> 🚀 **在线体验：**(体验点这里) [https://1eakkkk.github.io/liuyao-tool/]

## ✨ 功能特点
- **0依赖**：纯前端，一个 HTML 文件搞定。
- **完全自动排盘**：自动计算纳甲（干支五行）、六亲、六神、世应。
- **六十甲子日柱**：内置完整六十甲子，起六神、算空亡一键搞定。
- **基础入门集成**：内嵌八卦、五行生克、断卦入门表格，边用边学。

## 🛠️ 技术栈
HTML5、CSS3、原生 JavaScript（无第三方库）。

## 📖 使用方法
1. 点击 **"起卦排盘"** 标签，选择起卦日的**干支**。
2. 点击 **"摇卦"** 按钮，系统会模拟三枚硬币、从初爻摇到上爻。
3. 自动生成完整的卦象表格，包含世应、六亲、纳甲、空亡。
4. 结合 **"基础知识"** 和 **"断卦入门"** 标签页学习对照。
