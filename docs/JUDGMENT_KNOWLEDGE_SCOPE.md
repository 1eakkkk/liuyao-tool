2026-10-02。本阶段只梳理现有资料和使用边界，不新增古籍、不补造传统规则、不接入生产。依据现有知识库及[知识层约定](KNOWLEDGE_LAYER.md)、[阶段 8A 报告](PHASE_8A_REPORT.md)、[来源与范围](READING_SCOPE_AND_SOURCES.md)、[判断修正](JUDGMENT_CORRECTION.md)、[精简候选审查](JUDGMENT_COMPACT_REVIEW.md)。

## 现有材料能支持什么

本次本地 corpus 校验通过：1 个版本来源、9 个转录段、10 个命题单元，7 个单元准入、3 个排除，未收录 Commentary 或 Cases。版本为 `phase8a-month-combine-hardening-1`。这些是**转录与整理的审核状态**，不是传统全体系、独立专家共识或预测有效性的认证。

当前只有《增刪卜易》1925 年文明书局版本。原文转录、版本定位与图像审查形成来源链；项目的 `normalized_statement`、适用条件、排除条件和例外整理均属现代整理。世应段标为历史注释，其余下表段落为原正文，不能混称同一种原文。哈希只能核对字节，不能替代外部真实性核验。

## 真正缺少的条件与分歧

**尚无准入的“问题类别→用神选择”材料。** 当前材料不能提供求财、事业、考试、感情等常见问题的完整取用规范，也不能将提示词中的惯常映射自动升级为已审核文献。这里的缺口是可核查依据不足，不是断言这些取法全都错误。

特殊游戏升段是否主取官鬼，个人免费娱乐网站是否主取父母，以及妻财、兄弟等候选的相关性，均不能凭项目常识确认是传统规范。需明确当前目标、所选角色、替代取法及适用理由；若方向依赖未核实的取法，保留不确定性。现有库没有足够材料裁定唯一用神或传统流派权重分歧。

| 尚未准入的单元 | 未收尾的条件 |
| --- | --- |
| [日合语境](../knowledge/units/zsby-day-combine-context-001.json) | 日／月／动爻等合的主体须分清；后文用神有气、失陷等限制尚未完整整理，不能把六合统一改写成生扶或阻滞。 |
| [回头作用范围](../knowledge/units/zsby-return-scope-001.json) | 后续日月对变爻的作用边界未纳入，不能外推任意全盘作用。 |

这 3 项仍为 `source_checked`，不是可用的已审核取法。9 个转录段通过不抵消命题条件未审核。其余缺口包括：综合旺衰、喜忌的判定前提，多个关系竞争时的主次标准，以及传统取象如何联系现实目标的明确论证。当前没有足够材料把这些缺口伪装成统一结论。

## 三类问题的输出边界

以下为本项目拟采用的**现代整理政策**，不是古籍引文或已验证模型能力。

| 提问类型 | 应有输出与停止边界 |
| --- | --- |
| 纯事实核对 | 核对程序已经计算的爻位、六亲、动静、关系及其事实 ID；资料只解释对应名称。无需为了答事实而选用神、判趋势或推现实结果。窄资料包没列的事实不能解释为不存在。 |
| 普通建议 | 依据用户说明给出可执行建议，并标明一般建议或现实条件。练习、复盘、安排时间等不能反过来成为卦盘支持、抵消阻碍或证明方向的证据。 |
| 趋势提问 | 先明确目标、时间范围及必要机制；区分程序事实、取象假设、作用解释和当前方向。取法缺依据时说明限制，不以数量投票或有利／不利各出现一次强填 mixed，也不强迫唯一用神或偏吉偏凶。 |

类象不能确认真实能力、心态、竞争强度、热度、政策、回报或朋友权限。相同关系在不同所选角色下可能有不同解释，必须说明作用对象与当前目标；条件分支不能偷偷替换用户的现有目标。完整背景资料不要求全部成为依据，只声明实际使用的字段与来源。

## 本阶段离线收尾条件

1. 固定上述准入清单与缺口，保持原文、历史注释、现代整理及来源字段可区分；不为收尾晋升 `source_checked` 或增加篇数。
2. 形成三类问题的离线输出约定：程序事实可引用，取象假设和一般建议分别说明；未获依据的主取、权重和现实推断不能被格式通过掩盖。
3. 用已曝光案例和最小正误对照核对遗漏属性引用、关系方向、条件串台、抹去月合评价、建议充当证据、标签与理由冲突；保留失败与无法确认。开发对照不称新样本验收。
4. 工程检查证明字段、来源、原始回答及审核引用可回放；内容审查单独判断支持度与归属。闭合的是有限范围和离线实现，不是补齐传统全体系或证明模型语义改善。

## 后续新样本验收建议

先冻结候选身份、输出约定和审查标准，再生成此前未用于调词的新问题；覆盖三类提问、普通目标与机制不明的特殊目标，保存原始输入、回复和版本。不能继续把这两条曝光问题的反复调试当独立验收。

两名审查者独立逐段核对事实、范围、支持、主次取用及方向一致性；使用文献时另核对具体字段与出处归属，记录精确原文引用。未知取法标 uncertain，保留分歧，不能因机械 validated 改成内容通过。只有确实隐藏身份且隔离开发反馈的设计才能称盲审；新增样本本身不保证盲测。

内容通过至多证明该批回答符合冻结标准。预测准确需要另行设计可观测结果、时间窗及独立记录，本阶段不据此作预测有效性或总体提升声明。
