# 当前架构

更新：2026-10-09。Vite 构建的原生 JavaScript 静态网站，没有服务端业务进程。旧函数位置见 [迁移映射](MIGRATION_MAP.md)，统一数据约定见 [DATA_SCHEMA](DATA_SCHEMA.md)。

```text
手动录入 / Cannon 物理投掷 + 日期
                 ↓
core 排盘 → Canonical 卦盘 → cast-store
                 ↓                 ↓
          确定性规则标注        页面与历史快照
                 ↓
       结构化会话 + 问题 + 可选公开背景
                 ↓
       DeepSeek API / 导出提示词并贴回
                 ↓
       接收完整性、轮次与引用核对
                 ↓
       正文 + 可展开依据 → 本地历史与追问
```

## 模块职责

| 目录 | 职责 |
| --- | --- |
| `src/app/` | 初始化、事件、共享状态、卦盘快照及重置流程 |
| `src/core/` | 历法、纳甲排盘、Canonical 归一化、物理投掷 |
| `src/rules/` | 从统一事实计算局部关系，独立输出规则结果，不决定吉凶 |
| `src/ai/` | 普通解读、模型请求、费用及可选背景查询 |
| `src/ai/output/` | 结构化上下文、消息、返回协议、接收解析与依据呈现 |
| `src/storage/` | 设置、历史、迁移、主观反馈及判断登记 |
| `src/ui/` | 页面组件、投掷窗口、历史、主题与表单交互 |
| `src/styles/` | 布局、主题和响应式样式 |
| `public/vendor/cannon.js` | 独立加载的 Cannon 0.6.2 物理引擎及许可 |

程序卦盘是事实来源；规则结果不写回或另造一套卦盘。模型解释不会修改原始爻位、六亲和日期记录。可选公开背景与个人问题、卦盘事实分别传入，背景不是预测证据。

## 当前结构化路径

`src/ui/reading.js` 接收 API／导出／贴回／追问操作；`session.js` 准备同一卦盘和当前问题；`selection.js` 生成完整依据目录；策略 7 由 `practical.js` 提供基本规则与结构要求。API 通过 `strict-transport.js` 接收一次工具数据返回，外部 AI 回复走相同解析与呈现路径。

`parse.js` 检查轮次、返回完整性和结构，当前版本不使用旧内容质量门槛拒绝整篇回答。正文可读而附带结构异常时，`view.js` 显示正文和提示，`reading-history.js` 保存同一可读内容。协议细节见 [STRUCTURED_OUTPUT](STRUCTURED_OUTPUT.md)。

普通解读仍保留自己的文字请求和显示路径。旧协议代码用于历史兼容和离线研究，不代表新会话仍启用那些取法门槛。

## 运行与发布边界

- API Key 和历史只在用户浏览器本机存储；服务商请求由浏览器发出，本站不代持统一 Key。
- 刷新、重新进入或长时间返回清空当前工作区；不自动恢复旧的活动解读。保存的历史可单独查看。
- `experiments/`、`knowledge/`、测试及验收记录不随生产包发布。
- Vite 使用相对资源路径与 ES2020 目标；`release:check` 检查实际打包模块及发布文件清单。
- 原始单文件基线在 `tests/regression/baseline/index.html`，对应导入提交 `1964881`；它用于兼容对比，不代表当前产品界面或默认策略。
