# 判断登记备份与独立列表

日期：2026-10-05。本轮补齐原计划M5的本机导出/导入与历史删除后的登记查看、结果追加。纯前端，本轮API调用0。

## 操作

AI页面展开历史后，进入下方“判断登记”。独立列表保留登记时的问题、原回答与卦盘、固定判断/标准/截止日期和追加结果。原历史被删除或裁剪后，仍能查看、补记和导出。原回答按需展开，长内容可滚动，登记表单随重绘保留草稿、展开状态和焦点。

选择JSON备份后先检查并预览新增/追加/重复数量。点击“确认合并导入”才保存。支持单条“登记与结果”文件，以及顶部“登记与反馈”总备份中的registrations；普通历史与事后feedback不在此次恢复范围。没有判断登记的旧反馈文件会明确提示不能导入。

## 数据规则

- 同编号、同固定哈希：仅合并未出现过的结果，不替换本机结果。相同结果的字段顺序变化不造成重复。
- 编号或对应历史相同但判断/标准不同：整批拒绝，不静默覆盖。
- 整批字段、日期、版本元数据与原快照哈希检查后一次写入。任一错误不部分导入；本机损坏、哈希冲突、容量失败均保留原数据。
- 文件不超过5MB，最多500条登记，每条100条结果；合并后也检查容量。先预览不写入，确认时重验文件与本机数据，异步核验期间本机变化则要求重新预览。
- 只接受白名单快照及标量元数据，不恢复设置或Key。导出快照重算哈希与登记时一致。
- 导入不生成新的“事前登记”时间，保留原时间/哈希，另外标明从文件恢复。文件中的时间未被独立核实；哈希不是可信时间戳，不能认证预测或阻止用户改本地数据。结果记录仍由用户填写，不自动算准确率。

## 验收
