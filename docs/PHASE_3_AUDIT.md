# Phase 3 审计与验收

## 范围与结论

依据完整阅读的 REFACTOR_PLAN.md、PHASE_REPORT.md、ARCHITECTURE.md、DATA_SCHEMA.md、MIGRATION_MAP.md，逐项审计原计划 §17 Phase 3，并参照 §16.1 核心测试范围。本阶段只补测试和文档，不新增业务规则、AI 结构化输入或知识库，不进入 Phase 4。

## 1. Phase 0～2 已实际完成的要求

原有 71 项测试是测试用例数，不等于固定排盘 fixture 数。原有磁盘 fixture 为 24 个；核心矩阵在一个测试中运行 64 个静卦及 384 个单动爻组合，动态调用权威旧版作为期望结果。

| Phase 3 要求 | 已有证据 | 原有缺口与本轮处理 |
| --- | --- | --- |
| 50+ 固定排盘 fixture | 24 个完整输出 fixture，另有动态组合矩阵 | 冻结矩阵中已有的 64 个静卦期望值；替换动态期望，不重复执行静卦场景 |
| 六十四卦覆盖 | 64 静卦、384 单动爻与旧版完整字段对照 | 增加卦名唯一、八宫各八阶段的明确断言 |
| 空亡测试 | 卦盘完整字段对照包含空亡，矩阵跨全部 60 日柱 | 增加六旬边界与 12 地支空亡命中的独立断言 |
| 世应测试 | 64 卦完整结果包含世应字段 | 增加世应各唯一、相隔三位、各宫阶段世爻位置断言 |
| 六亲测试 | 本卦和变爻六亲的旧版对照 | 增加 25 种五行关系方向断言及变爻仍以本宫计算断言 |
| 动变测试 | 全部单动爻；固定样例另有三、四、六动 | 补二动、五动；对两个混合阴阳本卦遍历全部 64 种动爻掩码 |

此外，既有 Canonical 无损往返、日期、物理落地、存储迁移、Prompt 和 AI 回归继续保留。它们不作为凑足 Phase 3 核心覆盖数量的依据。

## 2. 原来缺少的核心不变量

- 六十四卦唯一，八宫各包含八个阶段；世应各一个、相隔三爻，世爻符合宫内阶段。
- 六旬空亡在所有 60 日柱及 12 地支上正确命中；六神按日干起点循环。
- 生我／我生、克我／我克方向明确；变爻六亲使用本卦宫五行，不能切换为变卦宫五行。
- 多动时只翻转指定位置，静爻没有变爻数据，无动爻时变卦为空；二动、五动此前未覆盖。
- 核心拒绝非法六爻输入；固定输入和元数据得到确定结果，且不修改输入。

## 3. 是否需要新增测试

需要少量补测。旧版等价性只能证明迁移保持原行为，不能发现新旧共有的逻辑错误；原有 24 个落盘 fixture 也未达到 50+ 固定 fixture 要求。无需重复增加静卦、单动爻或既有 AI／存储测试。
