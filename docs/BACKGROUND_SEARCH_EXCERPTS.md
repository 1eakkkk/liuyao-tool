# 2026-10-04 联网背景第二阶段：短搜索与公开原文摘录

本阶段围绕原目标——减少未知对象臆测、使解读依据可查。只完善背景检索，不扩大古籍、解读协议或模型等级；没有调用解卦模型，也没有部署或宣称解读质量已通过。

## 本轮改动

复用上一阶段共同输入和恢复处理。原生搜索改为非思考模式、单个明确查询，要求简短原生引用而非长介绍。一次请求及服务端次数／tokens 限制仍不是全局硬保证；超限、未知用量、未完成或无结果的处理没有放宽。

接口可能返回链接而没有引用摘录，因此增加显式可选的公开网页读取。`searchWithPublicExcerpt` 仅在搜索已完整结束、用量已知且符合请求限制、但缺摘录时读取一次选定的搜索来源。其他错误不触发读取或重新搜索；读取失败保留已发生的搜索用量。普通 `searchBackground` 仍拒绝无摘录的结果。

读取服务使用 [Jina Reader](https://github.com/jina-ai/reader) 的公开页面 JSON 接口，只发送选定的公开 HTTPS URL，不发送 DeepSeek Key、待解读问题或查询词。请求禁止重定向，省略凭据和 Referer，有响应大小限制，支持取消；不接入自建后端或新密钥。第三方服务和源站仍可能限流、返回过时内容或失败，不能保证永久免费或可用。

来源记录标明 `excerpt_origin=public_reader`、`reader_provider=jina-reader`，不冒充搜索接口的原生引用或本站独立验证。返回的页面 URL 必须精确匹配搜索来源（忽略 fragment），限定公开域名，不支持 IP、本地名称、带凭据 URL 或末尾点主机。源站 DNS 与阅读服务内部行为不由本站验证；不把这些有限校验描述成完整 URL 安全审计。

从转换后的页面中取连续相关段落，优先对应标题，纳入紧邻前一段，并保留同节限定。超过 1200 字直接拒绝，不静默截断。摘录仍不是全文核验，其他章节的限定可能缺失；它是外部数据而非指令或程序卦盘事实，不能从局部摘录补造全文、用户实力或结果。

## 有限真实验证

仅一次新付费请求，源码 `7267b94`，查询“王者万象棋 官方 玩法”。从 `https://gua.1eak.cool` 的 Chromium/Edge 浏览器来源调用：HTTP 200，`end_turn`，实际一次搜索，output 138 tokens，文本 156 字符。上轮过长／截断和两次搜索的问题没有在此请求重现；一个样本不证明稳定性。请求仍无结构化引用摘录，因此原生搜索单独结果被拒绝，而非判为全部通过。

随后尝试浏览器直接读取搜索返回的官方公告，因跨域／传输失败不能读取。匿名 Jina Reader 从同一浏览器来源取得 HTTP 200，返回页面 URL 精确匹配，页面正文 3449 字符。读取的是 [8月27日版本更新公告](https://pvp.qq.com/web201706/newsdetail.shtml?tid=807732)，涉及“王者万象棋·迷你战”**限时玩法**，不能据此确认独立主游戏的完整玩法或段位机制。

利用两份实际响应离线复放完整组合流程，得到带来源的原文摘录并保持“限时／迷你战／9月主游戏”限定；不是第二次搜索调用或重新生成。API 与提示词共同输入能携带摘录，恢复后上下文哈希一致。原单独搜索的无摘录失败记录保留；“有可读原文”不等于该来源适合回答原段位预测问题。

实际 input 6133、output 138、合计 6271 tokens；不计缓存优惠，按高峰输入 ¥2／百万、输出 ¥8／百万的费用上界 ¥0.013370。本轮只一次付费搜索，未重试，公开读取没有提供支付凭据。[DeepSeek 定价](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。没有把读取服务的匿名可用性宣传成永久零成本承诺。

原始请求、回复、匿名读取结果、组合回放存于本机忽略目录 `test-results/background-search-short-20261004`。未提交凭据、完整模型思考、加密结果内容或网页全文。
