# 引用事实与解释分离：第一段离线实现

2026-10-02。依据用户确认的五步路线，先完成有限的离线协议与展示原型，不修改正式网站、不调用模型、不扩大付费预算。本段完成不代表内容验收或预测验收通过。

## 已实现

新协议 `evidence-led-offline-1` 默认先显示直接回答，最多三条因素；程序依据、解释假设与适用限制默认折叠，一般建议单独显示。正文不设凑字目标，字段有最大长度以限制体积。没有强迫填所有六亲、用神候选或应期。

模型只选择已有事实／规则编号，不再另输出事实值、完整规则结果或整串纳甲字段。程序从可信的当前 context 生成事实值、中文标签、规则方向及完整来源事实；规则与来源去重展示，不因重复引用提高权重。未知编号、额外 facts/value/result 字段、重复因素身份、跨 context 或更换固定任务均拒绝。

协议单独保存 `decision`：任务、方向、至多一个主要取用假设、主要因素、需权衡因素及取舍说明。主要取用的六亲必须来自本卦实际记录；非 unclear 的趋势判断必须直接关联主要因素。偏有利／偏不利必须有对应主要作用；mixed 必须明确列出相反主要作用并填写取舍说明。这是结构约束，**不会因为支持和阻碍同时存在自动计算 mixed，也不证明文本已解释合理牵制**。

纯事实核对与普通建议无需取用或趋势标签；此离线阶段任务由调用者显式提供，不是已完成的问题自动分类器。事实任务只能列 neutral，不加建议；一般建议独立保存，不能成为主要因素的编号。趋势取法不足允许 focus 为空、方向为 unclear，限制字段不可冒充预测支持。

沿用现有程序的事实来源闭包与去重，不改变排盘和规则算法。新协议与正式 `structured-answer-1.0` 分开；旧会话、提示词导出、历史记录、API 流程保持原版本。没有新增付费执行器。

## 明确的能力限制

自由文字仍可能偷偷重述没有引用的属性、作无依据现实推断，或者用空泛取舍填满必需字段。当前检查器不自动判断这些文字正确；把焦点 ID 加进主要因素只能修复链接，不能证明相关性。不得将 `structure_and_links_only` 宣称为内容通过。

假设和限制字段不是免责模板，正文越界不能由尾部免责声明抵消。所有用神角色和关系作用仍需独立内容审查。现有知识库缺少已审核的完整问题取用规范，详见 [知识有限范围](JUDGMENT_KNOWLEDGE_SCOPE.md)。本段不新增古籍数量、不晋升未完成条件审查的条目，也不注入线上知识。
