# 结构化核对：生成前检查支持范围

## 本次问题与行为

旧正式版把许多趋势问题强制设为依据不足，仍调用模型补一般建议，再把程序预定的不足包装为 AI 判断。此次仅修正使用流程与归属展示，不扩充传统取法、不放宽准入、不接入未通过的三层候选。

新入口名称为“结构化核对（试用）· 有限观察”，提前说明目前不支持成败预测。缺少适用取法或本盘缺所需关系时，在 API、提示词导出及追问的生成前拦截；不调用解读接口、不生成外部提示词，也不新增一条假问答历史。既有背景查询费用另计。

能力说明明确已经有卦盘，区分缺少取法与缺少对应关系。六爻基本事实可在本地展开，不需 AI；用户可主动切换普通解读，保留问题和卦盘，但不自动发送。普通解读不具备同等取法准入核对。彩票中奖预测另有能力说明，不用卦象可靠估计中奖概率或开奖结果。

已有受准入的协助题显示“条件性观察”，不包装成成败判断。程序事实核对、明确一般建议仍走原协议；其他旧策略的请求、响应校验与历史身份不升级。原始回复不修改，历史里仅对完全匹配已发布固定不足文案的结构化回复加支持范围说明，把全文收进详情，不重新分类任意 AI 文字。

## 验证与发布

验证范围：未覆盖首问与追问零解读调用、无外部导出、无虚构历史；查看六爻；主动切换不提交；受支持的导出、贴回、API及历史流程；旧协议；公开背景确认；三种屏宽的 Chromium/WebKit。所有接口使用模拟回复，不读取真实 Key、不付费调用。

当前工程与浏览器检查已完成部分，发布前补齐结果与源码身份。具体上线记录以本文最后一节为准。
