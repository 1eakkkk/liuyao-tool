# 取法准入阶段：按用户明确选择推进

用户在版本3真实内容仍未通过后选择：先核对取法再参与判断，接受暂时更多依据不足。因此本阶段的目标是让模型只能在已核对的取法范围内解释，而不是继续为无来源的象意补免责声明。上一批停止状态、原文、争议及费用均保留。

## 首版覆盖和限制

策略4使用独立、版本化的取法准入卡。首卡只整理《增删卜易》所述彼此扶助方向，绑定现有转录段zsby-1925-s1及其文本SHA、影像第146页和明确出处。独立Luna核对了引文、定位及适用范围；这是针对所给转录的语义复核，不是新增独立人工原典认证，不证明个案有效或预测准确。

程序只接受简短、单一方向的明确协助问题，并且实际卦盘存在对应的世生应/应生世程序记录。引号、复合句、选择或反向帮助问法暂不覆盖，不假装普遍理解意图。匹配后只准入对应basis_id、帮助方role_id及perspective；assessment仅conditional/neutral，不能由相生直接判成功、实际意愿或能力。application.mapping_id不能自造，不把原知识库association_only条目改成程序事实或预测证据。

没有同时匹配问题和卦盘的卡时，模型看不到可选盘面依据；schema锁定none、空factors和unclear，并给出准确的“取法覆盖不足”说明。可以独立给一般建议，不能补取象来规避准入。个人免费项目维护、自用书目整理当前没有适用卡，故不推吉凶。这是用户已接受的覆盖收缩，不把它叫作已学会这些领域。

初版尚无已核对的成败方向规则，**结构化趋势解读会保留依据不足**；首卡只是可展开的条件性观察。普通事实核对、一般建议及普通解读保持原路由。旧策略1–3及旧历史不会升级，API与导出共用策略4及同一准入表。新会话上线后才使用策略4，旧历史保留身份。

## 固定验收

工程覆盖来源转录哈希、错误目标/混合方向不准入、实际规则与对象身份约束、伪造mapping_id/决定性作用拒绝、原两题空依据、API/导出/历史和窄屏。原版本3真实请求须字节相同，不修改旧结果。正式发布须独立来源范围复查、工程检查及有限真实流程通过。

本阶段最多3次真实调用、独立账本预留上限¥0.40，钱包至少保留¥1，不释放旧批预留。顺序固定：新增协助方向正向流程题（固定人工盘），原个人免费项目题，原自用旧书题；后两题原问题/盘面保持不变，新增题不替换原题，不称盲测。每题完整协议且主审/Luna的constraint-rubric-2事实、范围、支持、出处全部pass后才进行下一题；fail/uncertain即停止，不自动重试。

正向流程用于核对已准入卡的使用与边界，后两题检查未覆盖目标是否诚实停止取象。通过只说明这一有限准入版本可用，不表示这些原题已有可用吉凶判断，也不表示旧版本3内容通过。未经过核对的领域仍不覆盖，后续逐条扩充有出处、适用条件和反例的取法卡，而不是放宽主判断。
