# 结构化解读第三轮改进

## 产品变化

- 新会话采用 reading-production-3，API 与提示词共用同一要求。未通过校验的历史回复保留在本地供查看／复制，但后续请求只携带该轮问题与 answer:null、checked:false，不继续引用失败原文。格式通过的历史也仍标为模型判断。
- 明确提示用户未询问时间时不补充应期；建议型问题最多两项直接相关因素，不列举无关爻后再说它们无关。此为模型要求，不是对任意自然语言都已生效的保证。
- 增加范围有限的动静核对：明确“第某爻为动／静爻”及引用数量可绑定的“几爻均为动／静”与本卦事实不一致时回退。否定、疑问、条件、引用原话和变卦／变爻／伏神语境不猜测。不等于完整语义校验，未识别表达仍可能漏检。
- 失败原因改为可读说明，区分不完整、格式错误、重复字段、卦盘轮次不匹配、引用缺失、候选不一致、动静冲突；保留原文且可单独复制，无自动付费重试。
- 折叠详情区分程序事实和规则标注，规则来源事实另行展开；没有应期时不显示空应期段落。历史文本保存相同来源事实和失败原因。
- 复制本次对话包含折叠的依据与不确定性。
- reading-production-2 旧会话按原协议恢复和续接，保证历史 context_id 与未完成的外部提示词不失配。新版校验和失败历史隔离适用于新建会话；不偷偷改写旧回复或历史判断。

## 真实开发回归

原累计 20 元授权内进行了两组共 4 次 Flash 调用，均无自动重试：首组 3 次（事实核对、建议、追问），追加 1 次已曝光建议题的定向复测。它们不是独立盲测，也不验证预测准确率。

首组 3/3 格式与引用存在性通过，没有额外应期；建议回复仍出现无关爻和局部引用不足，象意推论不能视为已证明。追加回复格式通过，却把真实的第六爻动爻写成静爻。修复前明确记录其失败，不以格式成功掩盖事实错误。

随后停止付费调用，新增有限动静检查并离线重放：首组仍为 3/3 机械通过，追加回复正确回退为 motion_fact_conflict。真实原文作为回归夹具保留。**四条回复只有三条通过当前机械检查；这三条仍不代表语义验收通过。**

本轮保守单价估算成本合计约 ¥0.192618，精确扣费以服务商账单为准。保留全部预算预留，不因响应短或失败释放预留；当前累计预留约 ¥18.599638，上限 ¥19.95，低于用户授权 ¥20。原始回复、引用事实与费用结果归档于 acceptance/reading-v3-live-review.json。

接口依据：[DeepSeek JSON Output](https://api-docs.deepseek.com/guides/json_mode/)、[模型定价](https://api-docs.deepseek.com/quick_start/pricing/)。JSON 输出不能替代本站协议和事实检查。
