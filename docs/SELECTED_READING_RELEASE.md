# 2026-10-05 结构化选择版发布

## 本版变化

模型选择短编号，程序生成事实、基础五行关系及引用。属性位置只用于主要取用定位，因素使用明确关系或规则；主要取用最多一处，因素最多四条。程序去掉同一回头关系的两种重复编码，世应关系也不与其基础方向重复呈现。倾向由模型解释取舍，不按因素数量评分，不强行使用“利弊并存”。

纯事实核对仅针对明确“只核对／只确认／仅核对”请求，识别第N爻、初爻、上爻；程序按所问属性展示。明确要求一至三项建议、材料筹备的请求不强塞盘面依据。解析是有限关键词规则，不宣称通用语义分类。其他问题沿用有边界的象意解读。

可选“核实背景”默认折叠：只查询公开对象，一次 DeepSeek 搜索，必要时一次 Jina 公开读取，用户确认后使用。问题变更取消确认，后续追问不自动继承。限时／迷你来源由程序在模型请求前排除，保留原文、链接、检索时间和排除说明。此门槛保守，可能排除同页中的主游戏信息，暂不开放例外。其他资料仍需核对对象、版本和适用范围，不是自动事实认证。

API 和提示词导出共用 structured-selection-2。旧历史仍按原版本恢复。新格式绑定上下文，校验拒绝不存在的编号、外部来源混入卦盘依据、版本混用、已知的属性重述，以及漏审来源。重述检查是窄正则，不覆盖全部中文事实或隐含推断。来源最多五条；纯建议允许无因素，趋势需要主要依据。未通过回复保留原文，不自动修复或重新付费。
