# 判断主次与月令摘要修正

2026-10-01。用户提供游戏升段与私人娱乐网站两条结构化回复：事实大体对应，因素作用、取用理由与最终“利弊并存”之间缺少论证。本次修正面向稳定网站，不增加知识注入或自动吉凶评分。

## 已实现

- 新摘要准确区分得力数量较多、减力数量较多、数量相同及月令缺失；不把 4:2 与 2:4 写成“爻数相当”，不由计数给出整体吉凶。新排盘生成新版摘要，旧记录仅在展示及格式化时修正已知旧文案，原存储保留。
- 新结构化会话使用 `reading-production-4`。API 与外部提示词来自同一准备函数。输出 Schema 不变，仍支持偏有利、偏不利、利弊并存、暂不明确，没有默认强制标签。
- 要求说明主要取用角度、主要因素、次要因素及取舍；一般建议不能充当盘面支持，不能按因素或引用条数判定方向。
- 生克冲合空伏须解释作用对象和相关性；不机械把回头克判坏，也不机械把官鬼受克判好。类象不能确认现实中的心态、竞争、胜率、故障、政策、热度或回报。
- 仅对新会话追加判断指引；`reading-production-2/3` 的恢复、旧上下文与原始回答继续保留。两条反馈不被改判或覆写。

## 两条反馈的验收准则

| 问题 | 必须改进的解释 | 不允许的处理 |
| --- | --- | --- |
| 游戏升段 | 明确取用与关键因素，说明支持和阻碍的相对作用；未知游戏机制不得套用别的游戏 | 把练习、复盘等通用建议当作支持，再自动抵消阻碍 |
| 私人娱乐网站 | 保留免费、熟人娱乐目标，解释所选角色与动变的关系 | 自动把盈利或热度当目标；将官鬼取象障碍后直接把其受克归为不利 |
| 两条共同 | 标签、因素分类及结论一致，类比与现实事实区分 | 只因两面都有内容就填 mixed；所有候选并列却不说明取舍 |

这些是人工审查准则，不是关键词识别器。无法确认取法且结论依赖取法时应保留不确定性，也不能为增加回答差异而强制偏有利或偏不利。

## 检查与局限

新增检查覆盖两条实际卦盘的相反计数、数量相同与缺月令、旧摘要展示不修改原文、新版 API／提示词一致及恢复身份、旧 P3 恢复与四种标签继续可用。

冻结基线文件与卦例没有修改。兼容比较只允许已知摘要文案变更，其他排盘、AI 输入和存储仍逐项比较；原始旧模型失败保留。P3 真实动静冲突用其原版本回放，未替换原始 context_id。

本轮没有新 DeepSeek 调用或费用。提示规则已修订，真实模型是否更少模板化尚未验证；格式和引用检查仍不能自动证明因素权重、语义支持或预测准确。独立审查与发布记录随后附于本文。
