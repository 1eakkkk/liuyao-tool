## 使用与边界

历史详情的“判断登记与实际结果”中，新生成且首次回复通过格式/引用检查的结构化记录可选“结果发生前登记判断”。填写具体判断、可观察标准、截止日期，确认所登记结果尚未发生后保存。用户自行从原回复选判断；不要为模糊回答补造预测。登记不证明解释正确。

原回答、问题、卦盘、上下文/策略版本、登记时间和两组哈希固定保存；判断、标准、截止日期没有修改入口。一条历史仅登记一次，追问不会替换首次回答。实际结果以新条目追加，不覆盖旧结果。日期含截止当日；只接受登记当日及之后、今天及之前的结果日期。评价由用户填写，不由AI裁定。

已保存事后反馈的记录不能再补登为事前判断。旧记录缺校验信息、失败回复、仅导出提示词不开放事前登记，仍可用原有事后反馈。新登记保存成功仅清空结果说明，保留选择项与日期，支持连续补记。

登记与反馈分开存储。删除历史或清空历史/统计不删除已存登记；历史顶部“导出登记与反馈”可保留备份。导出只选择回答/卦盘/版本和用户填的结果，不包含Key或设置。损坏、超量、写入失败均保留原数据；不把失败保存报告为成功。哈希检查固定快照和标准是否与登记一致，不替代第三方核验。

本地设备时间、用户尚未发生声明均不能被本站独立验证，哈希不能阻止用户自行修改浏览器数据。此功能不是可信时间戳、不可篡改公证或预测准确率统计。
