## 新增入口

- `buildCanonicalCast`、`normalizeLegacyCast`、`toLegacyCast`：标准格式与旧格式的边界。
- `castStore`：唯一当前卦盘。
- `migrateStorage`：只读惰性迁移，成功保存时写入加法兼容格式。
- `initializeApp`：原事件注册和初始化的显式入口。

新增文件实际职责详见 ARCHITECTURE.md。
