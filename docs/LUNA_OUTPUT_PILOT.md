# Luna 结构化输出小样本预评测

日期：2026-09-24。性质：3 个开发样例的一次性预评测，不是独立 holdout、DeepSeek API 测试或预测准确率评测。

## 执行方式

用户授权使用 gpt-6-luna 子代理。三个全新上下文的生成代理各处理一题，指定模型 gpt-6-luna、reasoning effort medium；每题仅生成一次原始回答并保存文件，不运行校验器，不查看其他题目、实现代码或评分标准，不修复后重试。另一个全新上下文的同模型代理独立审查语义。

题目和评分维度在生成前固定。测试使用已有兼容卦盘及人工编写的开发问题：普通读书会筹备、只核对世应五行关系、要求改写六亲并虚构引用与概率的冲突指令。没有真实用户个人数据。

原始文件位于 `test-results/luna-output-pilot-01/`，不默认提交回答全文。`manifest.json`、每份输入与回答均记录 SHA-256。封印：`a7958c74be0f5dbad6a0551b113184c31226c83825e501d48dd896af5ece5a8e`。被测输出实现基于提交 `2806e8f`，过程中没有修改 Prompt、协议或校验器。

## 限制与下一步

- 仅 3 个定向开发问题、每题一次，无重复稳定性统计、Legacy 对照或不同模型比较。
- 生成与审查是分开的代理，但使用同一指定模型；不是人工盲评或不同模型的独立证据。主持者选题并知道预期。
- 通过文件向代理传递提示词，不等同 DeepSeek 的 system/user 消息传输、SSE 结束信号或参数组合。
- 文件完成由代理报告，未观测 API finish_reason；成本和 token 用量没有工具报告，保留 null，不能填 0 当作免费证据。
- 没有调用 DeepSeek API、读取或使用其 Key；子代理消耗 Codex 额度，不声称整个试验免费。
- 不证明六爻解释和预测有效；不据本次结果开放生产或自动知识注入。

若继续，先明确普通用户文字与引用相关性的要求，在新开发样例上检查改进，保留本轮原文和评分不变。真实 DeepSeek 接入仍待用户另行决定测试授权及预算。

## 工具

```sh
node scripts/prepare-luna-output-pilot.js test-results/<全新目录>
# 由全新生成代理分别读各 prompt.txt，一次性写入各 response.txt
node scripts/score-luna-output-pilot.js test-results/<全新目录>
```

prepare／score 均拒绝覆盖既有相应结果。评分器验证冻结输入和上下文后调用既有输出校验器，不生成、修改、修复或重新请求模型回答。重新运行是新开发试验，不能称为本轮重复独立验证。
