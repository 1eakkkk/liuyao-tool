# 界面改版

本轮仅调整界面与交互，不修改产品文案、排盘算法、解读协议或提示词内容。

- 浅灰背景、白色卡片、绿色主操作，减少金色装饰和持续旋转动画。
- 下拉框、日期、数字、文本框统一字体、边框、圆角、焦点和禁用状态；下拉选择保留原生键盘和移动设备操作。
- 复选框、按钮提供足够触摸区域，折叠标题使用原生按钮并同步展开状态。
- 手机使用底部导航，兼容安全区域；320px 窄屏的日期与时间分行，桌面排盘并列展示。
- 页面切换回到内容开头，支持系统减少动画设置，字体不依赖外部服务。

统一样式由 `src/styles/interface.css` 维护，旧样式保留布局与卦象绘制兼容；新控件应使用统一变量，避免另设边框、字号和圆角。

验收：`npm run test:browser:interface` 覆盖 320、390、768、1280px、控件一致性、溢出、弹窗、键盘折叠、移动导航和触摸区域，并核对改版前后的正文一致。历史浏览器基线继续验证提示词和流程；视觉一致性改为检查当前开发与构建版本，因为本轮明确要求改变视觉。测试拦截外部 API，不产生付费调用。
