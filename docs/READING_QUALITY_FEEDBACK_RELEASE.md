## 本机实际结果反馈

在历史记录详情中展开“记录实际结果”，选择主观评价、可选结果日期，填写观察到的结果。仅有提示词而无回答的记录没有反馈入口。

- 绑定首次问题、首次回答与卦盘快照；保存 SHA-256，用于检查绑定对象是否变化，不提供可信时间戳。
- 独立保存，不修改原回答。追问和会话重新归档不会覆盖已有反馈；原问题／首次回答／卦盘变化时拒绝改绑。
- 未保存的反馈草稿在同页面历史刷新时保留；刷新网页前需点击保存。
- 可以导出单条或全部回答与反馈。导出字段采用白名单，不读取或导出 API 设置、Key、人设配置。用户自行写进问题或反馈的内容仍会随文本导出。
- 删除／清空历史保留已保存反馈及原回答快照，可通过历史顶部“导出结果反馈”取出；仅本机浏览器保存，无上传、跨设备同步或准确率统计。
- 损坏的反馈数据停止写入；存储空间不足时不报告保存成功，保留当前输入。

这只是原始大阶段中“真实结果记录”的第一项基础功能，不等同于完成提前锁定、前瞻评价或训练数据集。
