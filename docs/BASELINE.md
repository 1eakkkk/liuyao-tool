## Behavior to preserve

- Cannon.js 0.6.2 physics (MIT), visible step/all modes and background simulation; no random substitution.
- Manual preview and correction; correction still consumes quota despite older comments.
- 10-minute/3-cast quota and 10-minute adoption of casts without a question.
- Local civil midnight; manually selected day leaves year/month/hour unspecified. Date-only solar-term boundary may be pending.
- Existing four-pillar, najia, palace, relatives, spirits, moving/hidden lines, seasonal and transformation calculations are frozen. No new rules engine.
- AI messages, presets, model IDs, prices, SSE, cancellation, usage and reply processing remain unchanged.
- Export writes prompt history; AI history groups follow-ups by session ID; old flat history is readable.
- Settings write failures show toast; automatic conversation persistence fails silently.
- Restored desktop plate has seven columns while fresh plate has nine; preserve this existing difference.
- History snapshot omits some raw metadata; old records lacking anchors use the existing restore fallback.
