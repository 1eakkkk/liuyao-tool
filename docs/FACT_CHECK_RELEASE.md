# 卦盘事实核对阶段发布

日期：2026-09-25。用户授权完成下一阶段开发后部署。

## 本次功能

在起卦排盘的卦盘下方增加“核对卦盘事实”折叠区。用户明确选择世应五行关系、动爻与变出六亲、伏神记录，直接从当前 Canonical 卦盘生成简短结论，并可展开对应依据。

这是显式主题的程序核对，不识别自由文本意图、不调用 AI、不消耗 API 额度。动爻核对不列静爻六亲；伏神核对不扩展到纳甲、旺衰或飞伏；世应核对说明生克方向，不推断现实胜负。缺少变出六亲时说明未记载，世应标记冲突时拒绝核对。

修改手动录入进入新预览后隐藏旧结果；生成新卦或恢复已有会话时重新绑定当前卦盘，重置所选主题与折叠状态。页面使用安全文本节点，不渲染问题或模型 HTML。

## 范围与限制

综合 AI 解读仍沿用现有 API 与提示词模式；本次不发布仍有语义问题的结构化 AI 输出，也不启用自动知识注入。它解决三类明确核对任务的范围与依据问题，不宣称解决任意自然语言问答或证明六爻预测有效。M3 的结构化会话、追问与完整产品验收仍待完成。

## 验收设计

- 新增 11 项测试：五种世应方向、无动爻不扩展六亲、缺失与冲突数据、24 份既有卦盘的字段范围、文本注入和换卦显示。
- 独立角色根据原始卦例编写 6 项验收样例，未读取候选实现；不是人工盲测。v1 验收自身把“没有变出”误判为越界，还错误要求本爻六亲；经规范复核后保留 v1、使用 v2，未为迎合错误验收而扩展产品回答。
- 新增桌面／手机浏览器验收：三类选择、展开依据、编辑时隐藏旧结果、重新排盘更新、无横向溢出、无 DeepSeek 请求。
- 原 Legacy 像素回归仅隐藏新增区域以继续核对原界面；新区域由独立浏览器测试覆盖，没有重写旧基线图片掩盖差异。
