# 完整卦盘结构化解读 · 2026-10-07

用户目标是可用的解卦：回答所问的事情，解释主要取用、支持与阻碍，给出取舍和建议。此前的少量取法准入卡阻断了多数问题，本版取消其对新会话的限制。

## 已发布行为

- 新会话使用判断策略 7、selection-2 格式；API 与提示词导出使用同一份消息与协议。
- 向模型提供完整本卦、变卦、世应、动静、六亲与日期关系目录。静卦、未知类别和未确认现实投入不再自动拒绝解读。
- 模型选择一个主要观察对象，最多四项解释；每项可组合引用当前目录里的有效编号。程序生成对应爻位、属性和引用，重复编号去重。
- 可选择偏有利、偏不利、利弊并存或暂不明确，不设置比例、不给固定默认答案、不按因素数投票。
- 仍检查完整格式、当前上下文、有效引用和主要取用对象。因素标签未形成固定组合不会拒绝整篇回答。用户没问具体应期时，不展示额外应期候选。
- 老历史保留原协议。旧版的取法准入与基础五行方向禁令不用于新会话。

## 本轮修复的显示故障

1. 新协议的不确定性数组最低数量与最终显示协议统一，避免符合请求 schema 的返回在显示时失败。

3. 推断倾向与因素标签不均衡时仍显示完整回答，避免有实质内容却被旧的一致性门槛拦下。
