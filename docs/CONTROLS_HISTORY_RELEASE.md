# 2026-09-27 控件、物理摇卦与结构化历史修正

## 本次范围

- 统一下拉菜单，支持日夜主题、触屏、方向键、首末项、Esc 关闭和标签聚焦；原生字段值与事件继续供业务逻辑使用。
- 物理摇卦改为点击投掷，移除拖动蓄势和按住提示，禁用投掷区域长按选择；保留逐爻与连续六爻、取消不扣次、未平放自动重投。
- 银绿色钱币 SVG 与主题配色桌面，精简弹窗文字，修正关闭按钮居中；未改变物理世界、正反面判定和排盘规则。
- 标题加大、四个统一线条导航图标，导航选中底色平滑移动、正文进入动画；尊重系统减少动态效果设置。
- 基础知识按章节折叠，帮助缩为三步；设置分组恢复四周留白。
- 单条历史删除新增确认；结构化提示词、贴回回复、API 解读与追问纳入统一历史。同一次解读仅有一条记录，未通过检查的原文明确标记，保存不重复累计费用。
- 当前仍保存在浏览器中的旧结构化会话刷新时补入历史。已被旧版本覆盖或清空的会话无法恢复。删除当前会话的历史后，刷新不会重新归档；当前解读仍可在页面继续查看。

后台自动起卦和可视化投掷均调用同一 CANNON 物理模拟，根据落定朝向判面。点击的时刻与位置提供初始条件，非直接随机抽取六爻结果。外观为 SVG 投影，不是用于决定结果的独立动画。
