# 六亲、世应明确断言：离线候选

2026-09-30。接续稳定化计划的解读质量阶段，不修改线上协议、提示词或校验行为，也没有付费请求。

## 支持范围

候选只检查 factors 中整个解释文本恰好是一句本卦事实的情况，例如“第1爻的六亲为父母。”、“本卦第三爻非世爻。”。允许数字／中文爻位、明确肯定与否定，事实来源为同一会话的程序证据表。

核对分开记录：断言值是否与程序事实相符；同一因素是否直接引用对应字段；所引规则是否提到该字段。规则提及不等于语义支持；另一段的引用不能替代本段引用。未知引用与缺失事实来源也分别记录。

疑问、条件、引号、变爻、伏神、多句解释及带推断的段落不符合当前句式，均标为 unassessed。该状态不是通过，不表示文字正确。answer、用神与时间候选等其他字段不在本候选覆盖范围。

## 开发结果

运行 `npm run audit:reading` 同时保留原人工标注基线，并输出 explicit-primary-candidate.json。原 102 个开发对照加上 66 个句式／语境对照，共 168 例符合预先写入各对照的预期。

这些对照包含 186 个因素段落：90 个明确断言被检查，18 个预置冲突被报告，36 处本段直接引用缺失被报告，96 个其他段落保持无法判断。数字仅描述构造的开发集，不是准确率。

已有四条已曝光真实回复合计 11 个因素段落均不符合整个段落单句的句式要求，候选检查数为零。原人工标注仍报告 15 项事实中 1 项冲突、3 处本段直接引用缺失；候选没有替代这些结果。

结论：候选的窄句式行为可重复，但真实覆盖不足，不满足生产自动拦截的门槛。不能用 168 例对照通过宣布内容质量或自然语言理解已通过独立验收。

## 后续

1. 保留候选和开发结果，不扩大关键词规则来追求表面覆盖。
2. 在离线输出候选中研究将可核对事实与解释、常识建议分开表达，并检查对原意、篇幅及引用的影响；现有协议保持兼容。
3. 准备固定评测材料时标明已曝光程度。独立验收需未参与调参的外部材料；真实模型复测前重新核对原累计费用账本，不能视为新增 20 元。
