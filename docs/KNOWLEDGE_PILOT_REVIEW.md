# 知识阅读包真实开发试测

日期：2026-09-30。共 3 次 DeepSeek 调用，使用现有测试 Key，包含一个失败样本和一组成对样本。样本来自已曝光的开发卦例，复核由开发作者完成；不是盲测、独立验收或预测准确率测试。

## 得到了什么结论

第一条无文献回复使用 `layered-reading-dev-1`，把月破规则结果塞进 facts。11 个原始事实值一致，但规则不是原始事实，机械检查失败，余下 5 个计划调用停止，没有重试。

据此修订为 `layered-reading-dev-2`：规则结果单列 rules，解释通过 rule_ids 引用，规则的全部来源事实必须同时列入 facts 与相应解释。保持原始事实、规则、文献、现实建议的区分，不将规则升级为独立证据。

另建一个只有月破问题的新开发计划，两条调用的协议与问题相同，仅文献资料包不同。两条回复都通过机械检查，目标规则的来源事实均无遗漏。这只说明本对照的格式、值和引用链可检查，不能证明解释全面正确。

| 修订后对照 | 作者复核发现 |
| --- | --- |
| 不给文献 | 解释名称时扩展到卯戌合、逢合填实等未提供文献的细节，超出本次狭窄范围；此处不将这些内容直接判为传统知识错误 |
| 给明确选材的月破文献 | 回答更集中于术语定义，但把现代编辑的禁用条件说成“该段也明确不推定无用、永久失效或吉凶”，存在出处归属错误；还枚举了不需要的六神等事实 |

因此不能发布知识增强。已有少量积极迹象，但来源归属缺陷仍然存在，且只有一个成对问题；月合、旬空尚未完成真实成对调用。

## 已进行的离线修正

- 文献包升级到 `explicit-literature-packet-dev-2`，用 field_origins 明确标记 original_text 是底本原文转录，摘要、适用／排除／例外条件和使用指导均为现代整理。
- 提示版本升级到 `layered-instructions-dev-3`，禁止将现代整理说成古籍原文明确规定，限制无来源的传统细则和无关事实枚举。
- 增加规则结果错值、缺少来源事实、原始事实冒充规则、未知／重复规则等对照。

这次提示修正没有再次调用模型验证；不能声称来源归属问题已经解决。人工支持与相关性复核仍必需。开发校验器仍不能自动识别自然语言中的归属错误。
