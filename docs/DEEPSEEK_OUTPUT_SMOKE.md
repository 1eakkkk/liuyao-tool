## 提示词 p2

保持 `structured-answer-1.0` 数据协议，将提示词升级为 `structured-answer-p2`：所有给人看的解释使用中文，不抄内部字段、布尔值、路径或引用 ID；引用只保留实际参与该段解释的依据，并说明与结论的联系。协议字段和引用 ID 本身保持原格式。现实建议明确为条件性解释，引用存在不能证明现实预测。

这属于生成要求，不是新增语义校验器。程序不会用简单关键词过滤器宣称解释正确，也不会静默改写模型原文。
