# 页面层级与设置面板改版

2026-09-30。源码 dd83d3a，按用户确认的暖白、墨灰、松绿方向整理整体视觉层级。

## 改动

- AI 输入、结果、历史取消外围嵌套卡片，改用留白、标题和细分隔线；解读与提示词为主要操作，设置、历史作为次要入口。
- 设置改为原生模态 dialog：桌面右侧面板，手机全宽。内部按 Key、回复风格、高级设置分组，保留原有字段与存储规则。
- 关闭按钮保持可见；面板内部滚动，背景锁定。支持 Escape、外侧点击、关闭后的焦点返回。选择菜单仍使用原有无障碍交互，挂在 dialog 内，避免被模态顶层遮挡。
- 保存、清除 Key 及单价操作的反馈在面板自身显示，避免页面 toast 被模态层挡住。
- 日间使用暖白，夜间改为墨灰；主操作保留松绿，动爻保留朱砂。排盘外框、空状态虚线框、手机逐爻卡片、学习章节的装饰框同步精简。
