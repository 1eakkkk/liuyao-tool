# 2026-10-04 联网背景第一阶段：接入准备，未上线

## 原目标与范围

原目标仍是个人／小圈子纯静态六爻工具：排盘事实正确、解读贴合当前问题、取象与现实分开、来源可查、少臆测。搜索只核实不熟悉的对象和必要公开规则，不查询私人状态，不证明吉凶、用户实力或预测准确率。没有扩展到通用搜索产品、登录、后端或新 AI 服务。

本阶段先验证现有 DeepSeek Key 的原生搜索路径，并完成 API 与提示词共同的**输入字段基础**。没有增加页面控件、改动解读输出 JSON 协议或部署；外部 AI 搜索来源的导入、来源展示及最终解读质量验收仍未完成，不能宣传正式支持联网解卦。

## 已实现

- 搜索使用固定 DeepSeek Anthropic Messages 路径；只发送用户明确指定的待核实对象／背景，不自动把完整问题或私人资料发给搜索。无新的服务密钥。
- 请求一次模型调用，参数请求一次搜索、2048 输出 tokens。**这些是请求限制，不能保证服务端遵守。**客户端只限制不重试、响应大小、取消和禁止跳转；用量超出请求或未知时拒绝使用结果，保留已返回的用量。拒绝结果不能撤销已经产生的费用。
- 仅识别原生 `web_search_tool_result` 结果，来源由结果块取得，不从模型自称“搜过”或自然语言链接抽取。来源限定 HTTP(S)、无凭据 URL、去重、最多五条；摘要只取带对应 URL 的引用摘录，不信任生成的总结。
- 共同输入 `input.background_search` 包含 `search_request`、`search_status`、`provenance`、`web_sources`、`background_claims`。`pending` 未执行、`failed` 失败、`no_results` 无结果、`retrieved` 返回来源；返回来源不等于事实已核实。没有可用摘录不能凭标题编造背景。
- API 和提示词导出使用同一准备结果；背景参与上下文哈希，保存／恢复维持该轮的背景；新轮次不自动沿用旧搜索。摘录及来源不加入排盘 `program_fact` 目录，不能借背景引用证明卦象判断。
- 新功能仅通过显式传入背景调用，默认正式路径和冻结输出不变。没有装一个没有真实执行能力的“联网开关”。

## 依据与真实检查

实现参考 DeepSeek 官方项目的原生搜索接口及结构化来源解析：[官方 provider](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/web/web-search-deepseek/src/provider.ts)、[官方说明](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/web/web-search-deepseek/README.md)。官方说明强调搜索消耗一次模型调用，并且不能把生成总结当作搜索来源。

无凭据 OPTIONS 检查允许 `https://gua.1eak.cool` 的 POST 及所需头。随后从 Edge/Chromium 的实际网站来源，只进行一次付费搜索模型调用，查询“王者万象棋是什么游戏，公开玩法和段位规则，优先官方资料”。没有调用解卦模型，没有重试。

接口 HTTP 200，确实返回原生搜索结果块；但 `stop_reason=max_tokens`，实际 `output_tokens=2163` 超过请求 2048，`web_search_requests=2` 超过请求一次。客户端先因未完整结束拒绝结果；随后离线回放原始响应，新增用量保护也拒绝该结果并保留费用。**不把能联网、返回链接等同于可发布。**生成总结和加密结果内容没有注入解读。

实际 input 5704、output 2163、合计 7867 tokens；按已核对的高峰输入 ¥2／百万、输出 ¥8／百万，不计缓存优惠，费用上界 ¥0.028712，低于本次 ¥0.20 预留。钱包调用前 ¥23.91，保留至少 ¥1。实际账单不由余额差额推算。[官方定价](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。

请求、原始响应、失败报告与离线保护回放保存在本机忽略目录 `test-results/background-search-20261004`，不提交凭据、完整思考内容或加密正文。首次失败保留，不重新解释为成功检索。

## 验收与下一步

四个相关测试文件共 36 项通过；冻结的 24 个输出保持一致；发布边界五资产通过。检查覆盖伪联网、未知／错误／截断结果、非法链接、来源去重、超限和未知用量、摘要来源错配、哈希绑定、API／导出一致、恢复与新轮次背景隔离。不是对真实网页内容或预测的验收，也没有声称进行了新一轮全量回归或真机检查。

独立 Luna 只读审查发现两项状态风险：未完成背景暂存可能附着到其他待处理问题，状态与来源标签校验过宽。已分别把背景绑定到准确的问题、完成后清除暂存，并限定四种状态的来源标签；加上完成后直接保存另一个 pending 问题、恢复后不遗留及状态错配对照检查。修正没有重新调用搜索。

**决定：保留线上正式版，本阶段仅归档候选。**下一阶段先解决检索完成性、请求限制的实际行为和可用摘录，然后再接入来源展示与外部回复导入。最终仍用有限小样本检查：是否正确识别对象、是否把搜索背景当作用户私人现实、是否解释取用和主次、是否遗漏来源。不继续扩充古籍或用搜索链接数量当作解读质量证明。
