## 产品范围

一念六爻是个人／小圈子非盈利工具。源码在 GitHub `1eakkkk/liuyao-tool`，纯静态前端部署于 Cloudflare Worker `liuyao`，正式域名为 https://gua.1eak.cool/ 。没有自建后端、账户、收费或云端历史数据库。

## 已可用

| 功能 | 当前行为 |
| --- | --- |
| 起卦与排盘 | Cannon 物理模拟投掷或手动录入；统一卦盘数据与确定性关系标注 |
| AI 解读 | 普通文字与结构化解读；用户自带 DeepSeek Key，浏览器直接调用 |
| 提示词 | 无 Key 也可导出；结构化提示词与 API 共用基本规则，可贴回完整回复并追问 |
| 结构化解读 | 策略 7，完整卦盘与六条基本规则；AI 自选取用、解释和取舍，取消旧取法覆盖及解答质量否决 |
| 回复异常处理 | 本轮完整正文可在附带字段异常时显示并保存；不伪称引用已通过，不自动付费重试 |
| 可选背景查询 | 查询公开对象、查看原文与来源、确认后使用；搜索与解读费用分开 |
| 本机记录 | 历史、主观反馈、判断登记与结果追加；判断登记可导出／导入，无跨设备自动同步 |
| 页面体验 | 起卦／AI 两项主导航、移动适配、日夜主题；刷新或长时间重返清空当前工作区，保留历史与设置 |

最新前端源码提交 `0d617a1`，Cloudflare 版本 `34fb5b02-7d4d-4fcd-898f-a495449a9b98`。之后的文档整理不改变线上程序。最终整站检查和线上两浏览器验收已通过；版本、资源哈希、真实测试费用与限制见发布记录。

## 保留为研究的部分

知识库自动注入、旧取法准入策略、问题分类与知识 A/B 等实验仍在源码、固定样例及 Git 历史中；实验目录存在不等于已上线。生产构建检查禁止引入知识库实验模块。冻结资料、失败响应和预算记录保留，不把格式检查成功解释为预测准确。

原始 Phase 0–5 的模块化、统一数据及确定性规则已经成为工程基础；Phase 6–8 的实验工具与部分知识研究已实现，但没有据此宣称完成整体预测效果验证。[原始方案](../REFACTOR_PLAN.md)只作历史参考，不能按阶段编号自动推进开发。

## 后续方向

先保持当前基本解答规则稳定。遇到实际问题，按“复现—定位—修复—相关验证—发布”处理，不用无限增加约束或付费样本替代可用性。解答应回应能够回答的部分并说明限度；不能保证模型掌握未知事实、预测准确或外部服务始终可用。
