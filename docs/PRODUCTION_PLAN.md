# 稳定版生产收尾方案（2026-09-24）

## 产品范围与收尾定义

用户确认：个人或小圈子非盈利使用；GitHub `1eakkkk/liuyao-tool` 保存源码；Cloudflare Worker `liuyao` 托管纯静态前端，沿用 `gua.1eak.cool`。保留用户自填 DeepSeek Key 和输出提示词两种解卦方式。首版先上线稳定功能，知识库增强独立验收后再发布。

本次不需要账号系统、数据库、付费系统或网站统一持有 API Key。达到以下条件即可结束首版工程，不必等 Phase 8 后续研究完成：

1. 当前稳定功能通过自动测试和桌面／移动宽度浏览器回归。
2. 发布包不含知识库实验、私人配置和测试资料；版本与资产哈希可追踪。
3. Cloudflare 预览资源、页面和关键流程可用；生产域名服务同一批已检查资产。
4. 源码改动保存到 GitHub；线上版本、回滚版本及剩余限制有记录。
5. 真实 API 本轮如未复测，必须明确标注；不能把模拟请求称为真实模型验收。原记录在 2026-09-15 已确认真实 DeepSeek、追问、刷新恢复和移动端人工验收。

## 实施顺序与交付物

### 1. 现状核验与范围冻结

核对 Git 分支、未提交资料、生产配置、Cloudflare 当前部署、历史人工验收。保留用户已有未跟踪的 `docs/PHASE_8B_2_HOLDOUT.md`，不擅自修改或纳入本次提交。记录当前线上版本作为回滚候选，发布前再次核验。

### 2. 发布工程补齐

- 修复浏览器验证脚本随机选中浏览器禁用端口的问题，采用各套件独立安全端口且冲突时明确失败。
- 把私人配置、环境变量文件、Cloudflare 本地缓存纳入仓库级忽略规则。
- 添加静态响应的 MIME 防嗅探和 Referrer Policy；保留既有资源兼容行为。
- `npm run release:check` 重新构建并检查实际模块边界、发布文件白名单，生成 `test-results/release-manifest.json`。清单记录 Git 提交、工作区是否有修改、各文件大小与 SHA-256，不含私密配置。
- GitHub 自动检查跑单测、构建边界、三套浏览器验证。部署保持显式操作，避免实验分支提交自动覆盖线上。

### 3. 发布验收

执行 `npm test`、`npm run release:check`、`npm run test:browser`、`npm run test:browser:structured`、`npm run test:browser:rules`。

覆盖桌面 1280／移动 390 宽度、基础页面、手动排盘、提示词、模拟 AI 首次／追问／恢复，以及显式实验模式兼容。遇失败先判断是产品缺陷还是测试环境问题，修正后只重跑受影响检查。

执行 Wrangler dry-run；上传候选版本后验证 HTTPS、主页面、JS／CSS／物理引擎、响应头、实际资源哈希及浏览器关键流程。真实 API 复测需要用户提供可用的测试方式，密钥不进源码、文档或发布文件。无 Key 仍可完整验收提示词路径。

### 4. 发布与回滚

使用版本上传与版本部署分离的流程，预览通过后发布同一个版本 ID，不重新构建另一批文件。上传和部署命令以本机 Wrangler 帮助及 Cloudflare 官方文档为准。

上线前记下上一生产版本。上线后核验 `https://gua.1eak.cool/`、资产哈希及主要页面；若资源缺失、关键功能异常或存储兼容退化，使用 `wrangler rollback <上一版本ID>` 回滚，不清空用户浏览器数据。

Cloudflare 参考：[版本与部署](https://developers.cloudflare.com/workers/versions-and-deployments/)、[静态响应头](https://developers.cloudflare.com/workers/static-assets/headers/)。

### 5. 交接与后续维护

交付 GitHub 变更链接、生产地址、版本 ID、回滚 ID、验证结果和已知限制。遇到用户报告的问题，通过“复现—修复—检查—预览—发布”处理，不持续增加与需求无关的测试。

知识库增强另开里程碑：修复任务范围与排除绑定问题；把已曝光失败样例转为回归；准备新的独立未曝光评测；通过零禁止注入／零异常门槛；再验证真实模型事实、引用、遗漏与成本；最后显式灰度接入。不能反复使用同一 holdout 后宣称独立通过。

## 当前限制

- 浏览器本地存储不跨设备同步，清理浏览器数据会丢失本地记录。
- API Key 由使用者本地保存，直接调用 DeepSeek；网站不提供统一密钥或费用代付。
- Android／Windows 壳源码不在本仓库，网页验收不等于重新完成壳程序验收；此次交付目标是网站。
- 单测通过不代表知识库效果通过，不代表六爻预测准确。

具体执行结果见 `docs/PRODUCTION_RELEASE.md`。
