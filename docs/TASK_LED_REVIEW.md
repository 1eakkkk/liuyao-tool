# 任务分流：程序核对、一般建议与趋势解释

2026-10-02。本阶段只开发隔离原型 `task-led-experiment-1`，不修改正式 API、提示词导出或历史记录；不覆盖上轮 v2 的失败回复、冻结协议和审查。

## 已实现的边界

- **事实核对**：调用者显式选择已有程序事实 ID，程序直接生成原值和标签；无模型请求、无解释、无吉凶。只有所选记录显示。未记载的 null 是记录状态，不证明现实不存在。没有实现任意中文问题自动提取字段。
- **一般建议**：模型只接收问题、任务、schema 和身份信息，不能看到卦盘、规则、历史或来源身份；返回一至两条建议和信息限制，不接受趋势或引用字段。同一问题即使卦盘不同，请求逐字相同。自由文字仍可能编造，因此仍须内容检查。
- **趋势解释**：程序继续展示原值与来源；模型结论只回应目标，因素解释负责关联依据，取舍用因素编号指代。保留主要取用／主次校验；不按数量定方向，不强迫 mixed 或吉凶分布。自由文字仍不能由 schema 自动证明正确。

任务类型目前由调用者指定，原型不能当作自然语言自动分类器；事实选择也不宣称理解任意用户问题。古籍候选没有注入，传统取法的完整条件与权重仍未准入。
