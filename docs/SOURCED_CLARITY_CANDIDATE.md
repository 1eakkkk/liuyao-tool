# 术语与出处边界：第二版离线候选

日期：2026-09-30。承接 [真实小样本对照](SOURCED_READING_LIVE_PILOT.md) 的“冲克关系”支持度分歧及自由文字归属风险。本轮开发完成新的提示候选、开发对照与三题准备资料；没有调用付费接口，也没有改变生产解读。

## 修订范围

新增 sourced-instructions-dev-2，输出结构仍使用 layered-reading-sourced-dev-1。第一版提示、真实调用、旧计划和既有校验器保持原样；不覆盖历史数据后再说旧实验通过。

- 六合、六冲、旬空分别称其对应关系；无额外依据，不扩写为生克、旺衰、实际效力或成败。
- 可以说“没有提供生克判断”，不能推成“盘中不存在生克”。否定句、条件句按完整含义检查，不做关键词封禁。
- 原文转录只支持实际写出的内容。本次引用的适用限制明确归给现代整理，并附相应现代字段的引文；只连接原文字段不够。
- 不把某段原文未提及的结论推成整部古籍或整个体系永远不存在；逐字匹配不证明外部影印本真实性。

这些要求同时覆盖结论、解释正文、适用性、不确定性和建议。输出优先简短回答问题，不为了篇幅增加无依据推断。这是提示修订，模型是否遵守仍需要新的真实回复审查。

## 开发对照与评价标准

[十二组人工正误对照](../experiments/reading-quality/sourced-clarity-controls.json) 包括六合与相生、六冲与衰弱、旬空与必败、未提供与不存在、片段与全体系、现代限制与原文、正确 source_claims 配错误自由文字，以及逐字匹配与外部真实性。它们是合成开发资料，不是模型回答或经典预测案例。

程序将 24 段对照文字分别放入五处字段，共 120 个机械连接组合。正误文字都可能机械通过，测试明确保留 unassessed 和 production_ready=false。这里的通过是在保护“机械检查不负责识别这些语义缺陷”的边界，不表示 80 条回答语义正确。

[冻结评价标准](acceptance/sourced-clarity-20260930/rubric.json) 要求人工逐句复核事实、范围、支持度、出处和核验边界。无法确认记 uncertain；不通过平均分或多数票隐藏分歧。未经查看的新题、外部原典核查和真实结果验证仍是单独门槛。

## 三题成对准备

```text
node scripts/prepare-sourced-clarity.js <新目录>
```

月破、月合、甲子旬空各有带文献／不带文献一对，共六份请求。这三类都是既有公开开发题，扩展的是新提示的题型覆盖，不称新盲测。

请求沿用旧三题的事实、规则、问题、文献及参数；仅 system 指令变化。原有保守预算保持不变，不通过降低余量美化成本。完整计划与导出提示词来自同一 messages，另保存评价标准和封印。新目录拒绝覆盖。准备无 Key、网络或账本操作；现有付费执行器在凭据加载前拒绝新计划。

完整六请求计划的理论预留仍为 1.14576 元，超过上轮账本未预留的 0.94246 元；**准备完成不等于允许执行完整批次**。下一轮真实测试须重新核对价格和原 20 元累计授权，先选择能容纳的较小固定批次，再封存，不私自增加授权或释放未知消费预留。
