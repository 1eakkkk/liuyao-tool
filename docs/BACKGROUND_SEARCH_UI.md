# 2026-10-05 背景确认页面与一次解读检查

本轮完成可选背景查询页面候选，**未部署**。它服务于减少未知对象臆测，不改变程序排盘，也不证明预测正确。沿用纯前端、用户自己的 DeepSeek Key；没有新后端或账户系统。

## 已实现的候选功能

- 结构化模式下增加默认折叠的“核实背景”。只填写公开对象名称，说明 DeepSeek 搜索费用及 Jina 公开读取。
- 一次搜索、必要时一次公开原文读取；显示来源链接、检索时间、原文及限定条件。不从模型说明编造出处，不自动重试。
- 用户核对对象和适用模式后才勾选使用。未确认的资料不进入请求；问题改变取消确认，重新勾选后绑定当前问题。
- API 与提示词导出使用同一份背景输入。开始操作前捕获已确认背景，防止旧会话清理或后台起卦丢失本次资料。背景不进入程序事实及卦盘规则证据目录。
- 完成结果、复制文本及导出历史保留原始来源和摘录；后续追问不静默继承背景。刷新、长时间返回、清空当前解读会清空当前背景，历史不删除。
- 支持停止查询、超时取消及迟到结果隔离；已收全的搜索用量只累计一次，失败时也保留已知费用。搜索费用按保守上限显示，与解读费用分开；用量不完整时费用未知。历史记录金额仍是解读调用金额，不包含搜索费。

没有接入外部 AI 自行联网后的新增回复字段；目前只支持本站确认的背景作为共同输入，以及既有 JSON 回复导入。没有承诺搜索服务稳定返回合适来源。

## 验证范围和结果

35 个输出相关文件、502 项检查通过；冻结的 24 个输出保持一致。候选打包通过。背景页面在 Chromium/Edge、WebKit 各 1280、390、320px 的六组模拟浏览器检查通过，包含未确认隔离、问题变化、API/导出共用、来源文本注入防护、刷新及查询中清空无复活。既有解读 WebKit 三屏宽流程通过，包含历史展开、导入、停止、替换及刷新。

以上浏览器用例使用模拟 API，不产生费用；不是实际 iPhone 真机检查。截图检查未见横向溢出。独立 Luna 复核清空路径及六组报告；初次审查针对旧清理条件的结论已撤回，最新代码按活动 controller 释放资源，generation 只限制结果渲染。

实际搜索和公开读取沿用 [上一轮响应](BACKGROUND_SEARCH_EXCERPTS.md)，没有再次搜索或读取。背景为官方“王者万象棋·迷你战”限时公告，不能当作主游戏完整段位规则。

## 有限真实解读：失败即停止

执行前封存一个已曝光的段位问题、原卦、上述背景及共用请求；不是盲测、随机样本或预测结果评估。仅执行一次 Flash 解读，非思考模式，最多 8192 输出 tokens，无重试。预留不超过 ¥0.30，余额保护底线 ¥1。

回复完整结束并通过现有格式/引用存在检查，但**整体内容验收失败**：

1. 第三、第五爻均金，第四爻世爻为水，却断言“两爻没有直接生扶世爻”，再据此排除支持作用。金生水，此处与输入五行及自身陈述冲突，不是传统取用争议或预测真伪。
2. 本段事实引用仍有遗漏：第一因素写“父母水”却缺本爻五行引用；第二因素写“酉金”却缺地支引用。候选理由中的亥水、变妻财等属性也未完全覆盖。现有检查通过仅代表结构和引用存在，并不覆盖全部语义。
3. 没有直接将迷你战公告套作主游戏机制，但也没有明确交代该来源不适用主游戏段位。不能把“未见直接套用”称为背景范围处理全部通过。

主代理和独立 Luna 一致确认五行作用冲突；Luna 对事实引用“基本相符”的结论只适用于属性值大致正确，主代理补充上述覆盖遗漏。未修改原回答获取通过记录，也未追加付费生成。
