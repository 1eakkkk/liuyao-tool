# 趋势引用包：程序展开来源与参与者

2026-10-03。新隔离实验 `packet-led-experiment-1`，不修改正式网页、旧协议和旧原始回复。目的为减少模型手填事实 ID 和漏引，**不把包成员正确宣称为解释正确**。

## 本段实现

每项解释最多选两个程序包、最多三项解释。角色包包含一个本爻／变爻／伏神的身份与状态；关系包包含原有一条规则的严格来源，以及该规则实际参与者的角色身份背景。模型只选包 ID，程序从可信 context 展开事实值和来源；不知道或跨 context 的引用拒绝。

规则的 `source_ids` 保持原样，不把六亲、世应身份等补充背景伪装成推导前提。程序显示 `rule_premise` 区分来源与背景；相同事实及关系去重，不从数量计算吉凶，也不证明两段解释独立。世应规则来源中其他四爻的“世爻否／应爻否”不会使它们成为关系参与者，不能借来满足主要取用。

本爻、变爻和伏神身份保持分开；有向关系沿用程序 from/to，飞伏比和无方向时仍显式含伏神与本爻归属。非 unclear 方向必须由主要解释覆盖选定角色；mixed 仍需要相反主要作用及合理取舍，而非同时出现两面就自动采用。

上下文只传趋势问题与程序包；关系包用 participants 指向已列角色包，不重复发送全部身份背景。程序展示时才展开。自由文字仍可能说出未选包的属性，或用免责声明包装现实断言，必须另外审查。没有新增文献、没有确认传统取法和权重共识。

## 实际结果：首例失败，按计划停止

计划两次，实际一次。私人照片小册回复在机械检查中因 `Invalid factor selection` 被拒绝：同一因素 f2 出现在主要因素和反向因素两份列表中。未调用第二个问题，无自动重试、无在线降级放行，原始回复没有删改。实际用量 6,481 输入／1,033 输出，共 7,514 token；最高价格保守估算 **0.021226 元**，不是已核对账单。完整 0.174600 元预留保留；执行前钱包 24 元。归档回放不访问账本，因此只能核对执行日志，不能独立证明真实扣费或账本余额。

两位独立审查者各检查实际这一条回复的六个维度，共 12 个维度、36 条可回放的 UTF-16 字段引文。这是已曝光开发样本的事后审查，不是盲测。两者均未接受事实引用覆盖、论证支撑及判断取舍：例如主要因素引用第3爻和世应关系，却解释第4爻官鬼金旺；另一因素只选变爻／伏神，却描述未选的本爻父母水与飞伏关系。整张盘中存在这些值，不代表本段引用已覆盖。

程序包减少了模型手填来源 ID 的负担，但不能约束自由文字只说包内事实，也不能证明“控制筛选标准”“推进容易”等现实解释成立。第2爻取用已被主要关系包的参与者身份覆盖，不能误报为全未引用。审查者对问题范围均通过；对主次与建议边界存在分歧（主次 A 不确定、B 失败；建议边界 A 失败、B 通过），保留原报告，不强行统一。

## 有限离线修复：每项因素只有一种主次

后续候选 `packet-led-priority-offline-1` 将每项因素改为单选 `primary / counter / background`；程序据此生成两份列表，同一个因素无法同时入两份。继续拒绝重复因素、未知引用和无覆盖取用，不根据因素数量计算方向。旧 v1 协议、冻结请求、失败原文及检查结果都保持不变。该候选仅有 8 项离线测试和独立复验，**没有真实 API 验证、没有部署**，不能据此宣称已修复上述内容失败。

独立复验发现新 schema 初版共享旧 schema 子对象、冻结时会影响旧对象，已改为深复制并重新验证。回放还发现若同时修改检查记录和汇总的 case ID，原先可被接受；现已绑定固定计划的 case ID，并核对“预留保留／语义未验收／预测未评价”等日志策略状态。修复记录保留在独立报告。
