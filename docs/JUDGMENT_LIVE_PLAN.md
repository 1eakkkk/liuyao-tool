## 人工标准先于回答固定

| 维度 | 核查内容 |
| --- | --- |
| 事实 | 爻位、动静、六亲、五行与关系一致；引用覆盖该段属性 |
| 范围 | 回答当前目标，不确认未知游戏机制，不换成盈利或商业成功 |
| 支持 | 事实→所选角色→目标作用的联系可读；类象不是现实确认，通用建议不充当盘面支持 |
| 主次 | 解释主要取用与因素取舍；备选影响方向时说明不确定性 |
| 标签 | 标签、因素分类和正文一致；mixed 需要具体牵制理由，不能按条数加权 |

每项分别记录通过、失败或无法确认，并引用原文说明。传统取法无法从提供材料核实则保留无法确认；不能因为没有反证就记通过。机械格式通过不替代人工结论，预测正确性始终为未评估。标准亦经独立审查 B 复核。

## 执行与预算

- 准备工具只生成固定计划与 SHA-256 封条，不读取 Key、不访问网络、不预留费用。
- 执行前重新生成同一计划，对照封条、价格核对日期、重复执行标记、重复预留与累计授权预算。预算不够时在凭据和网络之前拒绝。
- 按已核对的 [DeepSeek 官方高峰价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)预留全部输入未命中及最大输出，两个请求合计 **0.374436 元**。实际费用需记录完整 usage，估算上界与余额变化均不是精确账单。
- 准备时原账本限额 19.95 元（原 20 元授权内留有余量），已记账／预留 19.87234 元，剩约 **0.07766 元**，不足以执行。后续核实一批旧四次调用的完整用量并独立审计，释放 0.700474 元未使用预留；因此原额度已足够，未增加授权上限，不再需要此前询问的新增 1 元额度。无法确认的其他预留不动。
- 最多两次，传输、用量、完整性或机械检查失败即停，不自动重试、不现场改提示后重跑。
- 独立有界保存响应字节，再离线解析；格式损坏不截掉尾部。归档记录完整、截断或读取失败及字节哈希；HTTP 错误记录状态与脱敏后的有界响应体。原文、失败和整批预留保留。
