2026-09-28，站点源码 fead897。本轮不更改起卦算法、解读协议或模型请求。

## 已经解决，保持现状

- 默认进入起卦排盘，主导航只有起卦排盘和 AI 解卦；学习入口在页头。
- 基础知识及断卦入门章节可折叠；首次教程不会自动弹出。
- 标题已有书写体与印章，动爻已有朱砂色，夜间已有墨色配色。不再叠加纹理或外部字体。
- 物理摇卦弹窗已有六爻进度逐项点亮。

## 本轮修正

- 浏览器标题、页脚与问卦定位统一；操作统一为铜钱摇卦、手动录入、投掷方式、开始摇卦。
- 设置默认仅显示 Key 与回复风格；模型、人设、推理档位、估算价格归入高级设置。结构化模式继续隐藏不适用的人设、推理设置。
- 提示词导出改为三步短引导，备用操作仍折叠；删去未经本轮验证的模型“更准”宣传。
- 空状态显示六条灰色爻线，加强说明对比度及剩余次数提示。
- 世应、空亡、伏神可以在排盘旁点击展开；展开时占满一行，适配窄屏。
- 主题收为单一按钮，保留日间、夜间、跟随系统，支持外部点击和 Escape 收起。帮助按钮保留可访问名称及悬停提示。
- 禁止字体合成加粗。未把缩放图片作为真机字体缺陷的证据，也没有增加字体网络请求。
- 触控回归发现延迟滚动事件会关闭刚打开的菜单：改为仅在锚点实际移动时关闭，选项定位只滚动菜单自身。

## GitHub 自动检查遗漏修正

发布后 GitHub Actions 36421136552 的单元测试与构建通过，但 `test:browser` 在 `built restoredPlate` 比较失败：旧测试仍把有意更新的图例及新增术语说明与 v1 完整 HTML 逐字比较。上轮本地已运行的专项检查没有覆盖这处旧版恢复页断言，因此不能把上轮结果理解为完整 CI 已通过。

修正仅涉及验收脚本：对每个排盘结果元素继续精确比较，单独排除图例与术语辅助内容，并断言当前版恢复页的三项术语解释存在。保留提示词、请求载荷、对话恢复及开发版／构建版像素对照，不修改冻结旧版，也不调整网站运行代码。
